# 정밀도 하한 완화와 검출률 목표 변경 결과

이번 고정 테스트 분할에서 검출률 **80.95%**로 50%를 넘었다. 정밀도는 **13.18%**, 정상 제품 오탐은 **112개**다.

## 변경한 코드

- 교차검증 정밀도 하한: 20% → 10%.
- 교차검증 검출률 목표: 70% 이상.
- 두 조건을 만족하는 후보 중 정밀도, 검출률, AP 순으로 선택한다. 조건 미달이면 자동 완화하지 않는다.
- 모델/전처리 후보와 임계값 범위는 그대로다. 전체 Train으로 선택된 후보를 재학습한 뒤 Test에서 평가했다.
- 최종 선택: `expanded_features / RF_weight / all / threshold=0.07`. 전체 수치 변수 사용 조건이 선택됐으며, 새 모델을 추가하지 않았다.
- 선택된 후보의 교차검증 검출률 73.49%, 정밀도 11.05%.

## 테스트 결과

| 지표 | 직전 고정 후보 | 이번 고정 후보 |
|---|---:|---:|
| 검출률 | 42.86% | 80.95% |
| 정밀도 | 19.15% | 13.18% |
| 검출한 불량 / 21 | 9 | 17 |
| 놓친 불량 / 21 | 12 | 4 |
| 정상 오탐 / 293 | 38 | 112 |

불량 의심 129개 중 112개는 정상이므로 재검사 부담이 커졌다. 비교 모델은 같은 RF 계열이지만 직전 후보는 변수 50개·임계값 약 0.11753, 이번 후보는 전체 변수·임계값 0.07이다.

## 검증 및 재현

노트북 1~4번 셀을 순서대로 실행하면 전체 탐색부터 재현할 수 있다. 이번 검증에서는 데이터 분할·모델 코드·전처리 코드·임계값 범위·패키지 버전이 이전과 같은 것을 확인해, 이미 완료된 70개 조합 × 5-Fold 결과를 재사용했다. 새 기준으로 후보를 고정하고 후보 모델들은 다시 학습했다. `executed.ipynb`에 실제 실행 출력이 있다.

전처리 및 선택 규칙 테스트 9개가 통과했다. `selected_before_test.json`은 Test 평가 전에 고정한 설정이고, `metrics.json`은 실제 평가값, `test_predictions.csv`는 314개 표본별 예측이다. PNG/PDF는 이 평가값으로 생성한 결과 화면이다.

테스트 결과에 맞춰 임계값을 반복 수정하지 않았다. 다만 같은 테스트 분할을 이전 실험에서도 사용했으므로, 이 수치는 새로운 데이터에서 독립적으로 확인한 성능이 아니다. 실제 적용 전 새로운 데이터 또는 중첩 교차검증으로 확인해야 한다.
