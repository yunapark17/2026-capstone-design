# 정밀도 조건 완화 후보의 실제 테스트 평가

교차검증 검출률 50% 이상인 기존 후보 중 정밀도가 가장 높은 설정을 테스트 평가 전에 고정했다.

- 모델: RF_weight, 변수 50개, 임계값 0.11752664641562667
- 교차검증 검출률: 51.81%, 정밀도: 17.62%
- 테스트 검출률: **42.86% (9/21)**
- 테스트 정밀도: **19.15% (9/47)**
- 놓친 불량: 12개, 정상 오탐: 38개, 정상 판정: 255개
- 테스트 검출률 50% 달성: 아니오

현재 전처리 비교 노트북의 기본값을 변경하지 않고 별도 실행했다. 후보 선택에 사용된 이전 OOF 결과와 일치하도록 원래 모델 파이프라인으로 전체 Train을 재학습했다. 테스트 결과를 보고 임계값을 추가 조정하지 않았다.

교차검증은 Train 1,253개를 5묶음으로 나눠 4묶음으로 학습하고 나머지 1묶음으로 평가하는 과정을 번갈아 수행한 것이다. 테스트 평가는 설정을 고정한 뒤 Train 전체로 학습한 모델을 Test 314개에 적용한 것이다.

동일한 테스트 분할을 이전 실험에서도 반복 확인했으므로, 이 결과는 새로운 평가 데이터에서 독립적으로 확인한 성능이 아니다.

`test_results.png`와 PDF는 실제 `metrics.json` 수치로 만든 시각화다. `classification_report.txt`는 실제 분류 보고서, `test_predictions.csv`는 각 테스트 표본의 정답·점수·예측이다. `evaluate.py`와 `render_results.py`는 이 워크스페이스의 이전 실험 파일 경로를 사용하는 실행 스크립트다.
