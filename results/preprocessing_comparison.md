# 전처리 비교 결과

검증일: 2026-10-30 (Asia/Seoul)

**이번 비교에서는 기존 기본 전처리가 교차검증에서 최선으로 선택됐으며, 테스트 검출률은 42.86%로 목표 50%에 미달했다. 세 전처리 변경의 검출률 개선은 확인되지 않았다.**

## 변경과 비교 조건

- 새 분류 모델을 추가하지 않았다. 기존 RF, XGBoost, Logistic Regression과 가중치/SMOTE 설정을 유지했다.
- 기본 전처리, 결측 여부 표시 추가, 변수 200개·전체 사용, 절대 Pearson 상관계수 0.95 초과 중복 열 제거를 각각 비교했다. 여러 변경을 동시에 적용하지 않았다.
- 결측률 50% 초과 열과 상수 열 제거를 Pipeline으로 옮겼다. 중앙값, 상관관계, 변수 선택, 스케일링 및 SMOTE는 각 Fold의 학습 데이터만 사용한다.
- 결측 표시를 추가하는 조건은 수치값이 제거된 열의 결측 정보도 보존한다. 해당 Fold에서 항상 결측/항상 관측인 표시는 제외한다.
- 데이터 분할: 기존과 동일한 층화 80:20, random_state=42. Train 1,253개(불량 83개), Test 314개(불량 21개/정상 293개).
- 총 70개 조합 × 5-Fold = 350회 Fold 학습. 같은 전처리 중간 계산은 임시 캐시로 재사용했다.
- 기존 임계값 0.02~0.80, 0.01 간격 및 기존 F2 우선 후보 선택 규칙을 그대로 유지했다. Recall 60%·Precision 20% 동시 조건을 먼저 적용하며, 불가능하면 기존 fallback 규칙을 따른다.
- 전처리별 최선 후보는 Test 평가 전에 교차검증에서 고정했다.

## 전처리별 결과

교차검증에서 전체 최선으로 선택된 조건: **기본 전처리 (Fold 안에서 계산) / RF_SMOTE05 / 변수 상한 50 / 임계값 0.27**.
이 최종 모델이 실제 사용하는 변수는 50개다. 결측 표시도 변수 수에 포함되며, 상수·상관 필터 후 남은 수가 상한보다 작으면 남은 열만 사용한다.

기본 전처리의 결측 열 제거 위치도 기존 전체 Train 기준에서 각 Fold 내부로 옮겼으므로 원래 노트북의 교차검증 수치와 완전히 같을 필요는 없다. 네 조건은 이 Fold 내부 전처리 기준을 공유한다.

## 재현과 해석

노트북의 1~4번 셀을 순서대로 실행하면 교차검증 후보 선택과 네 조건의 Test 비교 표가 출력된다. 새로운 Colab 세션에서는 설치 셀 실행이 필요할 수 있다. 이 환경의 검증은 이미 설치된 동일 버전 패키지와 이전에 내려받아 확인한 UCI 원본 데이터로 수행했다.

전처리 테스트 7개 통과: 학습 데이터에서 계산한 중앙값·열 목록 유지, 결측 표시 보존, 상관 필터의 학습/검증 분리, 전체 변수/상한 제한 동작, 변수 이름 대응, 기존 선택 규칙 등을 확인했다.

테스트 불량 21개 중 11개를 검출하면 검출률은 52.38%다. 정밀도 20%는 교차검증 선택 조건이며 Test 정밀도를 보장하지 않는다. 이 테스트 분할은 이전 실험에서도 확인했으므로, 본 결과는 반복 사용한 분할에서의 비교 결과다. 새 데이터 또는 중첩 교차검증으로 성능을 추가 확인해야 한다.

실행 버전: `scikit-learn==1.9.1`, `imbalanced-learn==0.14.2`, `numpy==2.5.4`, `pandas==3.1.0`, `xgboost==3.4.1`.
